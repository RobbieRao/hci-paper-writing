# Changelog

## 0.2.0 - 2026-08-10

- Added a safe `.hci-paper/` workspace initializer with persistent claim,
  figure, reviewer-comment, revision, and policy ledgers.
- Added HCI-specific reviewer-panel and meta-review protocols that preserve
  disagreement and disclose simulated independence.
- Added a closed-loop rebuttal and revision protocol linking every response
  promise to a manuscript change and verification step.
- Extended the deterministic manuscript audit with reverse outlines, LaTeX
  figure/table integrity checks, and a versioned JSON schema.
- Expanded unit tests and documented the new workflows in English and Chinese.

## 0.1.0 - 2026-08-10

- Initial public release with contribution diagnosis, method-aware red-teaming,
  revision planning, local manuscript preflight, and bilingual documentation.
